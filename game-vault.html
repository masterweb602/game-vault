Export data

পুরো vault + played JSON file হিসেবে download হবে। backup করে রাখো।

Download full app (HTML)

পুরো app + তোমার data একটা single HTML file হিসেবে save হবে। যেকোনো PC/phone-এ open করলে data সহ চলবে। Claude Code-এ source হিসেবে দিতে পারো।

Install as app

Phone বা desktop-এ install করো — app drawer থেকে launch হবে, browser chrome ছাড়াই খুলবে।

Import from file

PC বা Android থেকে file নাও — .txt (এক লাইনে এক গেম), .csv, অথবা .json। existing data-র সাথে merge হবে, fuzzy duplicate skip।

নামের meta migrate

পুরোনো bulk-add থেকে আসা game-name-এ [2026][3.4 hours] বা [57 minutes] embedded থাকলে সেগুলো structured field-এ তুলে আনে। চালানোর আগে Export backup নিয়ে নাও। Manual ভাবে set করা year/playtime overwrite হবে না।

Played: month/day structured field-এ আনো

Played list-এ পুরোনো year-header paste থেকে আসা inline date (e.g. Oct 12) dateAdded timestamp-এ encoded আছে। সেগুলো item.month / item.day field-এ তুলে আনে। শুধু Played list-এ চলে। UI-add করা items আর Jan 1 fallback বাদ পড়ে। Manual month/day overwrite হবে না। চালানোর আগে Export backup নিয়ে নাও।
