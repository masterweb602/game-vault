Export data

পুরো vault + played JSON file হিসেবে download হবে। backup করে রাখো।

Download full app (HTML)

পুরো app + তোমার data একটা single HTML file হিসেবে save হবে। যেকোনো PC/phone-এ open করলে data সহ চলবে। Claude Code-এ source হিসেবে দিতে পারো।

Install as app

Phone বা desktop-এ install করো — app drawer থেকে launch হবে, browser chrome ছাড়াই খুলবে।

Import from file

PC বা Android থেকে file নাও — .txt (এক লাইনে এক গেম), .csv, অথবা .json। existing data-র সাথে merge হবে, fuzzy duplicate skip।
